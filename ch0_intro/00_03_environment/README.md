# 00.03: How the lab environment fits together

Draft lesson outline; detailed procedures and solution code will be added during authoring.

## Goal

Connect the repository directories with the services running in Docker.

## Planned activities

1. Locate dags, logs, plugins, config, and the local .env file.
2. Map the API server, scheduler, DAG processor, worker, triggerer, PostgreSQL, and Redis to their roles.
3. Distinguish source files from metadata and identify what cleanup removes.

## Checkpoint

Explain where DAG code lives, where tasks run, and which data persists.
