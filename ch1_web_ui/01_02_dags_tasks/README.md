# 01.02: Read a DAG and its tasks

Draft lesson outline; detailed procedures and solution code will be added during authoring.

## Goal

Relate a DAG's code and dependencies to its visual presentation.

## Planned activities

1. Choose a small example DAG that needs no external services.
2. Inspect its code and task dependency graph.
3. Compare DAG-level settings with individual task details.

## Checkpoint

Explain the order in which the selected DAG's tasks should execute.
