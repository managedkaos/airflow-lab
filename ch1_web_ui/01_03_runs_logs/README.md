# 01.03: Inspect runs, task states, and logs

Draft lesson outline; detailed procedures and solution code will be added during authoring.

## Goal

Follow a workflow from a DAG run down to one task's logs.

## Planned activities

1. Inspect a run and distinguish run state from task state.
2. Read task attempt details and execution logs.
3. Locate the evidence that explains a task's result.

## Checkpoint

Trace one task result back to its logs.
