# 01.04: Trigger and pause a workflow

Draft lesson outline; detailed procedures and solution code will be added during authoring.

## Goal

Practice controlling a small example workflow from the UI.

## Planned activities

1. Manually trigger the selected example DAG.
2. Observe task state changes and inspect the completed run.
3. Pause the DAG and discuss how pausing affects scheduled runs.

## Checkpoint

Identify the manual run and explain the difference between triggering and scheduling.
