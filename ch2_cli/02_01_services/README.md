# 02.01: Inspect Docker services

Connect service status and resource usage with the environment you explored in the UI.

## Planned activities

1. Run make status and interpret the service list.
2. Inspect resource usage and identify the worker container.
3. Use make logs to follow service output, then leave the log stream.
