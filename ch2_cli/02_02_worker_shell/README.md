# 02.02: Open the worker shell

Draft lesson outline; detailed procedures and solution code will be added during authoring.

## Goal

Inspect the Python environment inside the container where tasks execute.

## Planned activities

1. Connect with make shell.
2. Run pip list and inspect the installed Airflow and provider packages.
3. Locate the mounted DAG directory and exit back to the host terminal.

## Checkpoint

Distinguish commands run on the host from commands run inside the worker.
