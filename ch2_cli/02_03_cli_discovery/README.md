# 02.03: Discover Airflow CLI commands

Draft lesson outline; detailed procedures and solution code will be added during authoring.

## Goal

Find the commands supported by the installed Airflow version.

## Planned activities

1. Run airflow version and airflow --help inside the worker shell.
2. Explore the help for DAG, task, and configuration commands.
3. Inspect selected configuration values without displaying credentials.

## Checkpoint

Find the help for a command before choosing its arguments.
