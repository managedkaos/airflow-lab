# 02.04: Inspect and trigger DAGs from the CLI

Draft lesson outline; detailed procedures and solution code will be added during authoring.

## Goal

Operate a selected example DAG without using the UI to start it.

## Planned activities

1. List available DAGs and inspect a selected DAG's tasks.
2. Use the installed CLI help to trigger and inspect a run.
3. Find the same run in the web UI and compare the two views.

## Checkpoint

Correlate a CLI operation with its resulting DAG run in the UI.
