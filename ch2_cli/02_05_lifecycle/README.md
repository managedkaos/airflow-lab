# 02.05: Manage the lab lifecycle

Draft lesson outline; detailed procedures and solution code will be added during authoring.

## Goal

Practice stopping and resuming the local environment while preserving data.

## Planned activities

1. Stop services with make down and restart with the chosen up target.
2. Verify that source files and existing run metadata remain.
3. Review the destructive clean and nuke targets without running them.

## Checkpoint

Choose the correct target for a restart versus a deliberate reset.
