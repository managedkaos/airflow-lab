# 03.06: Schedule recurring runs

Draft lesson outline; detailed procedures and solution code will be added during authoring.

## Goal

Move from manual execution to a short, observable schedule.

## Planned activities

1. Choose a short lab schedule, timezone, and explicit catchup setting.
2. Unpause the DAG and observe a scheduled run.
3. Compare logical dates and data intervals, then pause the DAG after the exercise.

## Checkpoint

Explain when the next run is expected and distinguish it from a manual run.
