# 04.01: Handle failures and retries

Draft lesson outline; detailed procedures and solution code will be added during authoring.

## Goal

Use a controlled failure to learn how Airflow recovers from task errors.

## Planned activities

1. Introduce a predictable task failure and inspect its logs.
2. Configure a small retry count and delay, then observe another attempt.
3. Fix the cause and practice clearing or rerunning the affected task.

## Checkpoint

Explain retry behavior using evidence from task attempts.
