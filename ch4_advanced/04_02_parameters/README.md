# 04.02: Parameterize the workflow

Draft lesson outline; detailed procedures and solution code will be added during authoring.

## Goal

Change workflow behavior without editing the DAG for each run.

## Planned activities

1. Add a run parameter for a transformation threshold.
2. Trigger runs with different parameter values.
3. Validate the inputs and compare the resulting summaries.

## Checkpoint

Two runs with different inputs produce the expected different results.
