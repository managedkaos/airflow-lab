# 05.01: Build a parameterized summary DAG

Draft lesson outline; detailed procedures and solution code will be added during authoring.

## Goal

Create a new workflow that demonstrates the skills from the lab.

## Planned activities

1. Define a new DAG ID with extract, transform, and summarize tasks.
2. Support a configurable threshold, a retry policy, and a branch for empty results.
3. Validate the DAG, run it manually, observe a scheduled run, and pause it afterward.

## Checkpoint

Provide the DAG file, a successful normal run, an empty-result run, and evidence of the scheduled run.
