# 05.02: Diagnose a broken workflow

Draft lesson outline; detailed procedures and solution code will be added during authoring.

## Goal

Use both the UI and Docker-backed CLI to locate and explain a failure.

## Planned activities

1. Introduce a controlled import or task error in a copy of the workflow.
2. Collect evidence from service output, CLI checks, and task logs.
3. Repair the error and verify the result without resetting the database.

## Checkpoint

Explain the cause, the evidence, and how you confirmed the repair.
